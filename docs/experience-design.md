# 梦男前端与角色互动体验：本轮设计草案

日期：2026-11-17
状态：用户已批准 A 方案，直接实施。

## 推荐方向

保留 DS 的聊天结构与操作习惯，将入口和视觉重心转向角色互动。桌面采用角色入口、会话导航、聊天主体的清楚层次；手机上使用抽屉与单列编辑。浅色以暖白、石墨字和低饱和蓝为主，深色保持柔和层次；统一头像、按钮、输入框、间距、键盘焦点与保存反馈。不加装饰性功能说明或虚构使用数据。

## 本轮功能

1. **首页与回访**：展示已有角色卡、最近对话及继续聊天入口；无角色时提供创建和导入。未配置连接时提供明确设置入口。全部展示来自本地真实数据。
2. **角色管理**：角色搜索、收藏、复制、头像上传与预览；区分选择角色和编辑角色。复制使用新 ID，不改变旧会话；取消编辑不写入数据。
3. **会话导航**：按标题搜索、按角色筛选、置顶会话；列表显示角色身份。角色被删除后，已有会话快照仍可识别并使用。
4. **会话记忆**：增加用户可编辑的“本段故事记忆”，适合记录关系、约定、关键事件。每个会话独立保存，明确由用户维护；每轮构建请求时注入并计入预算。切换消息分支不会自动生成或改写记忆，界面说明其由此会话各分支共用。不进行付费后台总结。
5. **可靠交互**：编辑未保存时关闭弹窗提供保存、放弃和继续编辑；保存中禁用相关动作，失败保留输入。模型连接作为设置中的独立分组；角色会话的当前角色与库中待选角色区分呈现，避免误绑定。保存状态随编辑更新。

## 数据和实现约束

- 沿用 React、Zustand、本地 Node 服务、现有 UI 和语言体系，不增加框架。
- 新字段兼容缺省：角色收藏默认否，会话置顶默认否，故事记忆默认空。
- 原生 JSON 备份保存新增元数据与记忆；DS ZIP 保留现有格式，文档明确不会携带这些额外设定。
- 角色头像限本地图片，校验类型和大小，不访问任意外链，不执行角色卡内容。
- 会话记忆进入系统提示词，预算不足给出清楚反馈，不静默丢掉最新用户消息。
- 搜索默认只覆盖标题及角色名称，不宣称全历史正文搜索。
- 不创建新分支、不启用子代理；需要启动服务时使用可见终端。

## 验收

只测试新增数据兼容、记忆进入请求与预算、收藏/置顶持久化、复制角色 ID 隔离、备份恢复等改动路径。目视检查桌面与手机的首页、角色编辑、聊天和错误状态；完成后做一次汇总类型检查与构建。模型验证使用本地测试接口，不使用用户密钥产生费用。

## 可选取舍

- A 均衡版（推荐）：实现上述五项，兼顾界面、日常聊天与编辑可靠性。
- B 沉浸版：优先角色展示、聊天排版和视觉氛围；暂不加入故事记忆、收藏与置顶。
- C 创作版：保留现有视觉，优先故事记忆、角色管理和会话检索。
