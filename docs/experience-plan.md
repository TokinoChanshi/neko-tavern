# 梦男体验优化实施计划

> 按已批准的 A 方案在当前工作区直接实施；不创建分支、不启用子代理。采用 executing-plans 的逐项执行与定向验证方式。

**目标：** 完成角色首页、角色管理、会话检索置顶、故事记忆和可靠编辑体验。
**架构：** 继续复用 React/Zustand 与本地存储。纯规则单独放入 tavern/experience.ts；角色库拆出头像、记忆和离开确认组件。新增会话字段向后兼容，由前后端摘要同时投影。

- [x] 数据与规则：Character.favorite、Session.pinned/memory；摘要增加 characterId/characterName。实现复制角色、过滤会话、记忆注入和图片校验。定向测试旧数据兼容、复制隔离、记忆预算与备份持久化。
- [x] 角色库：搜索/收藏筛选、头像上传与清除、复制、区分编辑对象与新对话选择；未保存关闭保护、保存失败保留表单。角色库 UI 沿用标签和基础 Modal。
- [x] 首页：真实角色卡与最近会话、继续聊天、选择角色后开场白、连接入口、空状态；暖白/柔和深色样式和移动布局。
- [x] 会话：置顶和标题/角色筛选；显示角色身份。故事记忆编辑、保存和提示词接入，续写保持原请求快照。
- [x] 设置与可靠性：独立模型连接分组、首次配置入口、保存状态随输入刷新；复用未保存确认。修正角色上下文摘要同步。
- [x] 验收：新增用例通过后只针对修改继续检查；最后一次汇总类型/构建检查，在可见终端用隔离数据做桌面和手机 UI 验收，更新文档并关闭测试服务。

验证命令：`node --experimental-transform-types --import ./tests/register.mjs --test tests/experience.test.mjs`；最终 `pnpm test`、`pnpm type`、`pnpm build` 与改动文件 oxlint。
