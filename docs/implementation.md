# 梦男：本地酒馆客户端

日期：2026-11-17

## 已确认的范围

以 deepseek-ai/chat-demo 为代码基础，保留其 React 聊天界面、流式输出、消息树、主题及移动布局。增加本机 Node 服务、角色卡、用户人设、世界书、提示词预设、可配置模型连接。支持导入从 DeepSeek 下载的聊天记录并继续对话。保留上游 MIT 版权，不复制 SillyTavern 实现代码。

本机服务只监听 127.0.0.1，生产环境同时提供静态页面和接口；开发前端通过代理访问服务。启动命令在可见终端运行。聊天、附件、角色和连接配置存放在 .data（Git 忽略）中。无账号、多租户或云同步。

## 实施计划

- [x] 本机存储：`server/storage.mjs` 保存会话和附件；先落盘再替换内存，串行提交；导入暂存与正式数据分离。`src/services/chat/db.ts` 保持原调用接口，改用本机服务。
- [x] 模型连接：`server/provider.mjs` 提供 DeepSeek Messages 和 OpenAI Chat Completions 两类协议；将流转换成上游 UI 已识别的事件。配置 URL、模型和 Key；Key 存本地配置，不在导出中携带。
- [x] 本机 HTTP：`server/index.mjs` 提供配置、存储和模型接口，限制 Host/Origin、请求大小和静态路径；支持中止请求。`.data` 不作为静态目录。
- [x] 酒馆内核：`src/services/tavern/` 负责角色卡 JSON/PNG、用户人设、世界书、宏替换和提示词预算。世界书支持关键词、常驻、优先级和开关；只匹配当前分支。首版不宣称兼容酒馆全部扩展。
- [x] 对话接入：在 `store.ts` 的请求构建处插入角色提示词；将角色设定快照保存在会话中，支持给导入会话绑定角色。重生成、续写和分支切换使用对应历史。
- [x] 界面：新增角色库、人设/世界书/预设编辑器和模型连接设置，沿用 DS 的组件与样式变量；表单保留明确标签，保存错误可重试。
- [x] DS 导入：保留 v3 ZIP 解析、完整性验证、分支和图片。提交时追加并重映射冲突的会话和附件 ID；失败时原数据不动。保留 JSON 导出版本用于无损酒馆备份。
- [x] 文档与验证：补充 Windows 启动脚本、上游说明、许可证和数据格式限制；测试提示词、角色卡、存储合并/回滚、协议事件和 DS 导入。最后进行一次类型检查和生产构建，运行可见服务检查主要 UI 流程。

## 验收重点

1. 导入含分支的 DS v3 ZIP 后能查看旧消息并发送新消息。
2. 追加导入不覆盖现有会话，同 ID 的附件不污染原会话。
3. 损坏归档导入失败，原有会话仍可读取。
4. 角色、人设和世界书真正进入请求，未选中的分支不参与世界书触发。
5. 配置 OpenAI 兼容接口时，不发送 DS 专用工具与签名。
6. 本地服务重启后仍能读取会话和角色；导出不包含 API Key。

验证范围限新增与改动的逻辑；不创建新分支、不启动子代理。
